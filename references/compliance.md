# 合规与措辞红线

**所有与账号相关的固定文案与禁用表述写在账号档案里**（`fixed.image_footer`、`fixed.body_footer`、`banned`）。本文件给出**通用红线**与**各领域专项红线**，建档时抄进档案的 `banned` 字段。

## 通用红线

| 类别 | 禁用内容 | 原因 |
|---|---|---|
| 绝对化 | 「最好」「第一」「唯一」「全网最全」「永久」 | 广告法禁用 |
| 未验证结论 | 任何自己没核对过的事实、比例、参数 | 一旦被读者复现失败，账号信用归零 |
| 功效宣称 | 「治疗」「预防」「助眠」「减肥」「增强免疫力」 | 医疗／保健宣称 |
| 价格导流 | 「不到 20 块」「平价替代」「私我领券」 | 商业导流嫌疑 |
| 隐私信息 | 他人姓名、联系方式、地址、订单号、聊天截图 | 隐私与合规风险 |
| 平台敏感 | 违禁品、抽奖诱导、导流微信/二维码 | 平台规则 |
| 图片元素 | logo、可辨认品牌商品、人物肖像、水印 | 肖像权与商标 |
| 夸大对比 | 未经证实的「吊打」「碾压」「智商税」 | 贬损与不实对比 |

## 领域专项红线

### 酒类

| 类别 | 禁用内容 | 原因 |
|---|---|---|
| 酒精度 | 任何 ABV 数字 | 平台对酒类内容有明确限制 |
| 口感结论 | 「超顺」「闭眼入」「越喝越上头」 | 未经验证的主观断言 |
| 品牌 | 具体酒厂／品牌名 | 除非该篇本身讲材料区分，且用品类通用词（三秒橙酒、姜汁啤酒、干味美思） |
| 猎奇 | 「一口上头」「挑战 XX 秒」 | 诱导饮酒 |
| 人群 | 「孕妇也能喝」「开车前喝一杯」 | 安全风险 |
| 医疗 | 「降低血压」「护肝」 | 医疗宣称 |

### 食品

| 类别 | 禁用内容 | 原因 |
|---|---|---|
| 功效 | 「减肥」「降血糖」「抗癌」「养胃」 | 功效宣称 |
| 绝对化 | 「最好吃」「零失败」「一次就成」 | 广告法与不可兑现承诺 |
| 过敏缺失 | 未标注常见致敏原（坚果、海鲜、蛋、奶、麸质） | 健康风险 |
| 卫生 | 「隔夜也能吃」「不用洗」 | 安全误导 |

### 医疗健康

诊断、治疗、替代就医、个案当结论 —— 一律不写。

### 金融理财

收益保证、稳赚、荐股、借贷引流 —— 一律不写。

### 母婴育儿

婴幼儿绝对化建议（「一定不会过敏」）、偏方 —— 一律不写。

### 美妆护肤

功效承诺、绝对化表述（「烂脸救星」）、未备案产品效果宣称。

### 数码测评

未实测的跑分／续航结论、贬低竞品、隐性广告（未标注的返利链接）。

### 学习教育

保过／提分承诺、贩卖焦虑的绝对化表述。

## 数值与写法的精确性

这些小地方写错就会被内行看穿。档案的 `units` 字段记录账号自己的约定。

| 写法 | 不要写成 |
|---|---|
| 原始单位（`dash`、`少许`、`适量`） | 编一个具体数值（`1 滴`、`10 ml`） |
| 品类通用词（`姜汁啤酒`） | 近似但不同的东西（`姜味汽水`） |
| 精确品类（`白桃泥`） | 泛化品类（`白桃糖浆`） |
| 带空格数值（`50 ml`） | `50ml`（正文里空格保留） |

**记号也重要**：`dash` 写成 `1 dash` 不是 `1 Dash`。

**双量词不是重复**：`1 dash 苦精` 里的 `苦精` 是被量的对象，不要删。

**来源可查**：正文里出现的每个数字，都要能在档案的 `sources` 里找到出处；找不到就不要写。

## 配图的禁止元素

生图提示词里已固定排除，确认出图时也再核一遍：

- logo、可辨认品牌商品
- 人物
- 价格
- 领域敏感项（酒精度、疗效数字等）
- 任何额外文字（除了指定的角标、大字、对象名行）

## 发布合规提醒

- AI 生成图必须标注「AI 插画 · 非实拍」，避免误导。
- 档案里的固定提示（如「理性饮酒」「以实物为准」）不要删。
- 发布的笔记不可撤回，会立即进入审核。若用户只要求「填好」或「存草稿」，**不要点发布**。
