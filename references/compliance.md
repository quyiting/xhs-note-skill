# 合规与措辞红线

## 固定文案（不要改）

每张配图底部：

```
配方参考 IBA · 单杯份量 · AI插画 · 理性饮酒
```

每篇正文结尾：

```
配方比例与做法据 IBA 官网整理；配图为 AI 生成插画，非实拍。理性饮酒。
```

这两句是固定的，**不要每次改写** —— 改写会造成合规口径漂移。

## 禁用清单

| 类别 | 禁用内容 | 原因 |
|---|---|---|
| 酒精度 | 任何 ABV 数字 | 平台对酒类内容有明确限制 |
| 口感结论 | 「超顺」「闭眼入」「越喝越上头」「越喝越甜」 | 未经验证的主观断言 |
| 价格 | 「不到 20 块」「平价替代」 | 商业导流嫌疑 |
| 品牌 | 具体酒厂/品牌名 | 除非该篇本身讲材料区分，且用品类通用词（三秒橙酒、姜汁啤酒、干味美思） |
| 功效 | 「解酒」「养胃」「助眠」「补充维生素」 | 健康功效宣称 |
| 猎奇 | 「一口上头」「挑战 XX 秒」 | 诱导饮酒 |
| 绝对化 | 「最好」「第一」「唯一」 | 广告法禁用 |
| 医学 | 「降低血压」「护肝」 | 医疗宣称 |
| 人群 | 「孕妇也能喝」「开车前喝一杯」 | 安全风险 |

## 单位与写法的精确性

这些小地方写错就会被内行看穿：

| 写法 | 不要写成 |
|---|---|
| `1 dash` 苦精 | `1 滴`、`1 ml`、`一小勺` |
| `少许` 苦精 | 编一个具体毫升数 |
| `少量` 苏打 | `10 ml`、`20 ml` |
| `干味美思` | `甜红味美思`（这两者是不同产品） |
| `红石榴糖浆` | `红石榴汁` |
| `白桃泥` | `白桃糖浆` |
| `姜汁啤酒` | `姜味汽水` |
| `三秒橙酒`（Triple Sec） | `橙汁`、`橙酒`（中国语境下「橙酒」常指 Cointreau） |

**记号也重要**：`dash` 写成 `1 dash` 不是 `1 Dash`，单位前留空格：`50 ml` 不是 `50ml`（正文里空间保留）。

## 配图的禁止元素

生图提示词里已固定排除，确认出图时也再核一遍：

- logo、品牌酒瓶（可辨认的商标）
- 人物
- 价格
- 酒精度数字
- 任何额外文字（除了指定的角标、大字、酒名行）
