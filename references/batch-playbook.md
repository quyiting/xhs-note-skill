# 批次编排与数据复盘

## 句式配比

一个批次（通常 10 篇）按固定比例分配句式：

| 句式 | 篇数 | 用途 |
|---|---|---|
| 反常识／易错型 | 4 | 制造「我是不是做错了」的自我怀疑 |
| 数字／参数型 | 3 | 一眼看完，收藏动机强 |
| 顺序／流程型 | 3 | 讲操作先后，适合步骤类 |

一篇只用一种句式，避免整批同质。

---

## 发布波次

### 第一波（3 篇，错误类型互不重叠）

挑三种不同的错误类型：**漏一步** / **用错件** / **参数错**。钩子互不重叠，主色差异最大，信息流里不撞脸。

示例（调酒号）：自由古巴（漏材料）→ 莫斯科骡子（买错材料）→ 含羞草（比例错）。
示例（快手菜号）：番茄炒蛋（先炒谁）→ 糖醋排骨（先炸还是先烧）→ 炒青菜（几秒出锅）。

### 第二波（3 篇，数字型 + 顺序型）

数字型与顺序型交替，避免连续三篇同节奏。

### 第三波（4 篇）

剩余篇目。注意视觉形态不连续。

### 节奏规则

- **间隔 2–3 天一篇**，避免同一模板连续刷屏
- **视觉形态相近的两篇必须隔开发**（例：同为笛形杯的两篇、同为一张清单图的两篇）
- 第一波里**最强的一条**排最前（收藏转发动机最强的适合做首发）

---

## A/B 方法（不改素材，只换标题）

- 同一篇**不做双发**。
- 用**同句式两篇**对比：反常识型 4 篇看平均值，数字型 3 篇看平均值。
- 每篇观察满 **72 小时**再记数。
- 记录 `曝光 / 观看 / CTR / 人均观看 / 收藏 / 涨粉`，**直接抄后台数值，不换算**。

只看两个判断：

1. 本批**同句式** CTR 均值 是否 ≥ 账号基线（档案 `kpi.cover_ctr`）
2. 人均观看 是否 ≥ 账号基线（档案 `kpi.avg_watch_seconds`）

> 账号没有基线时只记录不判读，积累两批后再回填档案。

---

## 验收指标

目标线 = 档案里的账号基线（账号近 7 日均值）。

| 指标 | 基线来源 | 判读 |
|---|---|---|
| 封面点击率 | `kpi.cover_ctr` | 连续两批低于基线 → 回到选点与封面，不改措辞 |
| 人均观看 | `kpi.avg_watch_seconds` | 低于基线 → 封面过度承诺 |
| 收藏率（藏/观看） | `kpi.save_rate` | 收藏率是「有用」的信号，优先于点赞看 |
| 涨粉 | `kpi.followers_7d` | 不设硬指标，先看主页访客是否随系列角标上升 |

### 判读纪律

- **发布不足 72 小时不作失败判定**
- 单篇样本太小，一次改稿只看趋势，**不做因果断言**

---

## 异常归因

| 现象 | 归因 | 下一步动作 |
|---|---|---|
| CTR 上去了，人均观看掉了 | 封面过度承诺，点进来发现没兑现 | 大字卖点降一档强度；第 2 页要点卡提前 |
| CTR 没动，收藏率上去了 | 封面改动有效，曝光分配不够 | 换发布时间，而不是再改标题 |
| CTR 没动，人均观看也没动 | 改动没起作用 | 回到选点：卖点是否真的可验证、可复现 |
| 收藏率高，涨粉没动 | 内容有用但缺关注理由 | 强化系列角标与结尾二选一提问 |

## 单篇交付物清单

每一篇产出这 7 项才算完成：

1. 标题（主选 1 条 + 备选 2 条，主选 ≤ 20 字）
2. 封面大字（≤ 12 字，最多 2 行）
3. 封面主体描述（形态 / 材质层次 / 关键细节 / 主色）
4. 系列角标（`{系列名} · NN/NN`）或「本篇不做系列」的明确说明
5. 第 2 页要点 + 第 3 页三步 + 易错提示
6. 正文全文（含结尾提问 + 固定声明）
7. 话题标签候选（从档案标签池里挑）

批次交付时额外产出一份**批次总表**（编号 / 对象名 / 句式 / 主选标题 / 备选 / 首图大字 / 主色 / 计划波次），供排期与发布时核对。
